# hirosugu415.github.io

Hirosugu のポートフォリオサイトです。React + MUI + Vite で作っています。

https://hirosugu415.github.io/

## 開発

```
npm install
npm run dev
```

`main` にプッシュすると、GitHub Actions でビルドして GitHub Pages に公開されます。

## 写真の置き場所

- `public/assets/work/` … 社内システムの画面（ダミーデータ）
- `public/assets/other/` … そのほかに作ったもの
- `public/assets/rmemo/` … Rmemo

ファイル名は `src/content/work.tsx` と `src/pages/Home.tsx` に書いてある名前に合わせます。まだ置いていない写真は、点線の枠にファイル名が出ます。
